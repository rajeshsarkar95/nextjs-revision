# Next.js Revision Repository

A practical revision repository for Next.js App Router (Next.js 15/16), aimed at React/MERN full-stack developers.

## Getting started
1. Open this folder in VS Code.
2. Read the numbered folders in order.
3. Run the examples inside a Next.js project where applicable.
4. Use `16-interview-questions/` for interview preparation.

## Topics
1. Fundamentals and project structure
2. App Router and file conventions
3. Routing and navigation
4. Server and Client Components
5. Rendering strategies
6. Data fetching, caching and revalidation
7. Route Handlers (API endpoints)
8. Server Actions and forms
9. Hooks and navigation APIs
10. Authentication and authorization
11. Performance optimization
12. SEO and metadata
13. Loading and error handling
14. Middleware / Proxy
15. Deployment
16. Interview questions

## Version note
Examples use modern App Router conventions. Some APIs differ between Next.js versions. In Next.js 15/16, route `params` and `searchParams` are commonly asynchronous; check the documentation for your installed version. In Next.js 16, the convention formerly called Middleware is named Proxy.

## Useful commands
```bash
npx create-next-app@latest my-app
cd my-app
npm run dev
npm run build
npm start
```
