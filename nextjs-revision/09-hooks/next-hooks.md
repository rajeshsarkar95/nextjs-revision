# Important Next.js and React hooks

| Hook/API | Purpose |
|---|---|
| `useRouter` | Programmatic navigation |
| `usePathname` | Read current pathname |
| `useSearchParams` | Read URL query parameters |
| `useParams` | Read dynamic route parameters in Client Components |
| `useSelectedLayoutSegment` | Read active route segment |
| `useState` | Local component state |
| `useEffect` | Synchronize with external systems in the browser |
| `useRef` | Hold a mutable value or DOM reference |
| `useContext` | Read context |

Navigation hooks are imported from `next/navigation`. React hooks must be called at the top level of Client Components or custom hooks.
