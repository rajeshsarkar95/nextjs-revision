# Next.js interview questions

## Fundamentals
1. What is Next.js, and how is it different from React?
2. What is the App Router?
3. What is file-based routing?
4. What is the purpose of `page.tsx` and `layout.tsx`?

## Components and rendering
5. What are Server Components?
6. When do you use `"use client"`?
7. What is hydration?
8. Explain CSR, SSR, SSG, ISR, and streaming.
9. What is the difference between static and dynamic rendering?

## Data and APIs
10. How do you fetch data in a Server Component?
11. What are Route Handlers?
12. What is the difference between PUT and PATCH?
13. What are caching and revalidation?
14. What are Server Actions?

## Routing and optimization
15. What are dynamic routes and catch-all routes?
16. What is the difference between `Link` and `useRouter`?
17. What are Parallel Routes and Intercepting Routes?
18. How does `next/image` help?
19. How do you implement metadata?
20. What are `loading.tsx`, `error.tsx`, and `not-found.tsx`?

## Security and deployment
21. Authentication vs authorization?
22. How do you protect a Server Action?
23. Where should secrets be stored?
24. What is Middleware / Proxy?
25. How do you build and deploy a Next.js app?

## Practical tasks
- Build a dynamic `/products/[id]` page.
- Create GET and POST Route Handlers.
- Build a client-side counter.
- Fetch and render a list in a Server Component.
- Add loading and error UI.
- Add static and dynamic metadata.
- Implement a protected dashboard with server-side authorization.
