# Route groups and advanced routes

- `(group)`: organizes routes without adding the group name to the URL.
- `@slot`: named slot used by Parallel Routes.
- Intercepting route conventions such as `(.)`, `(..)`, `(...)` let a route render another route within the current layout context, often for modal patterns.

These are advanced App Router features. Use them only when the UI needs independent route slots or contextual navigation.
