# What is Next.js?

**Definition:** Next.js is a React framework for building full-stack web applications. It adds file-based routing, server rendering, data-fetching conventions, optimization, and backend request handlers.

## Why use it?
- File-system routing
- Server Components by default in the App Router
- Client-side interactivity when needed
- Rendering choices: static, dynamic, and streaming
- Metadata and SEO support
- Image, font, and script optimization
- Route Handlers and Server Actions

## React vs Next.js
| React | Next.js |
|---|---|
| UI library | React framework |
| Routing is usually added separately | Built-in file-based routing |
| Rendering setup depends on tooling | Framework provides rendering strategies |
| No built-in full-stack route handlers | Route Handlers are available |

## Create and run
```bash
npx create-next-app@latest my-app
cd my-app
npm run dev
```
Open http://localhost:3000.
